# Potato AI for Windows

Downloads for [Potato AI](https://potatobuilder.com), the AI Roblox game builder. This repository only holds the signed Windows installers; the source code is private.

**[Download the latest installer](https://github.com/DragonOptimizer/potato-ai-releases/releases/latest/download/PotatoAI_x64-setup.exe)**, or get it from [potatobuilder.com/download](https://potatobuilder.com/download).

- Already installed? Potato AI updates itself: keep it open (or reopen it) and it downloads and installs the new version.
- Every installer is signed with the Potato AI updater key, and the app checks that signature before it installs an update.
- Each [release](https://github.com/DragonOptimizer/potato-ai-releases/releases) lists the SHA-256 of its files (`SHA256SUMS.txt`).
